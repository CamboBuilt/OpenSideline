# Community code of conduct

OpenSideline aims to be welcoming to people of all skill levels, sports, backgrounds and abilities.

We expect respectful language, constructive code review, clear technical criticism, consent before sharing personal information, and patience with beginner contributors. Harassment, intimidation, discriminatory attacks, threats, doxxing, and unauthorized sharing of youth athletes' details are not tolerated.

Project maintainers may request edits, hide inappropriate contributions, restrict access or remove contributors for serious or repeated violations. If you need to report a concern, contact maintainers privately through an established project contact channel once published. Avoid posting sensitive details in public issues.

# Security policy

OpenSideline v0.1 is a prototype and does not offer security maintenance commitments or production-grade hosting.

**Please do not post live credentials, private player records, exploit payloads, or youth personal information in public GitHub issues.**

Before a maintained security contact is established, do not submit detailed exploitable security reports into public issues. Contact the project maintainers privately through available GitHub account messaging/contact details when published; do not assume public issues are confidential.

Supported versions: v0.1 is a proof of concept, not a supported production release.

# Privacy and youth protection: non-negotiable requirements

The prototype runs locally in a browser. It does not upload information to an OpenSideline server. Browser storage and exported JSON still contain whatever names users type and can be accessed by other users of the device, browser extensions, or anyone receiving the file. Treat player details as sensitive.

Before any public hosted launch:

- Obtain legal guidance on COPPA and other applicable state, national, school and sports-organization obligations.
- Support verified guardians/appropriate consent where required, deletion, access, correction, retention windows and abuse reporting.
- Design team/roster and minor-player profiles to be private by default and minimize personal data collected.
- Differentiate authorized team staff, guardians, spectators and the public. Public scoreboards should not automatically reveal minors' personal information.
- Require appropriate permissions to record and publish video or audio of participants, especially children.
- Provide clear moderation and user blocking/reporting tools, plus a defined incident response process.
- Encrypt sensitive data in transit and at rest for any hosted service and audit privileged access.
- Keep test data synthetic and avoid real names, birth dates, contacts, school names or minors' footage in public GitHub issues, test fixtures or demo streams.

Until these safeguards are implemented, **use synthetic test rosters only** for public demonstrations.
